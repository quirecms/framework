# Quire core

The engine of [Quire](https://quirecms.com), the extensible CMS for PHP on Symfony: content with revisions and reviews in PostgreSQL, extensions, themes, users and permissions, storage, backups, background jobs and the audit log, as a Symfony bundle.

New sites start from [`quire/skeleton`](https://github.com/quirecms/skeleton), which requires it. To run Quire inside an existing Symfony application instead, see [the database documentation](https://github.com/quirecms/framework/blob/main/docs/database.md).

See the [documentation](https://github.com/quirecms/framework/tree/main/docs).
